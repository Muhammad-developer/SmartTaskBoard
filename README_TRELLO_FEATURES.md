## 🚀 КАК НАЧАТЬ ИСПОЛЬЗОВАТЬ

### Установка
```bash
git clone <repo>
cd SmartTaskBoard
composer install
php artisan migrate
php artisan seed:run  # Optional, для примеров
npm install
npm run dev
```

### Запуск
```bash
php artisan serve
# Открыть http://localhost:8000
# Или использовать OSPanel (как у тебя)
```

### Создание первой доски
1. Зарегистрироваться на `/register`
2. Логин на `/login`
3. Автоматически создается "My Task Board"
4. Добавить колонки (кнопка "+ Add Column")
5. Добавить задачи (кнопка "+ New Task")
6. Переместить задачи между колонками (drag-drop)
